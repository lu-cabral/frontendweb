## 🚀 Como Executar

### 🔥 **Entrega-4 (Recomendado)**
```bash
# Clone o repositório
git clone https://github.com/lu-cabral/frontendweb.git

# Navegue para a Entrega-4
cd frontendweb/Entrega-4

# Execute localmente
npm run dev
# ou abra index.html no navegador

# Build para produção
npm run build
npm run serve
```

### 📱 **Outras Entregas**
Cada entrega pode ser executada abrindo o arquivo `index.html` no navegador.
